# sciona-atoms-ml

ML-oriented provider repo for `sciona.atoms.*` and `sciona.probes.*` namespace packages.

This first migration wave owns the clear-cut `sklearn` image wrapper surface under:
- `sciona.atoms.ml.sklearn.images`
- `sciona.probes.ml.sklearn.images`

`datadriven` remains out of scope until its ownership boundary is split more cleanly.
